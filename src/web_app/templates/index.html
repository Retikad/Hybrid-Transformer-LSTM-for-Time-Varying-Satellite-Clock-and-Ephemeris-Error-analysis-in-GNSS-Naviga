📚 About This Dashboard

🎯 LSTM Model

Baseline sequential model for time-series prediction. Good for capturing temporal patterns.

🔄 Transformer

State-of-the-art attention mechanism. Captures long-range dependencies in GNSS data.

⭐ Hybrid Model

Novel combination of LSTM and Transformer. Best performance on GNSS error prediction.

📊 ISRO Evaluation Metrics

  • RMSE: Root Mean Squared Error - primary metric
  • MAE: Mean Absolute Error - average prediction error
  • R² Score: Coefficient of determination (0-1)
  • Validity Periods: 15min, 30min, 1hr, 2hr, 24hr

💾 Data Requirements

Your CSV file should contain GNSS error data with columns such as:

  • timestamp / time
  • satellite_id / prn
  • broadcast_values
  • modeled_values
  • error (target)
